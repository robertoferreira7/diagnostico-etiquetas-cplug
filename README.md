# Diagnóstico Inteligente de Etiquetas CPlug — v18.10

Projeto estático pronto para GitHub Pages. Esta versão foi separada a partir do HTML fornecido, sem modificar as funcionalidades do aplicativo.

## Arquivos

- `index.html`: estrutura da página.
- `css/style.css`: estilos originais na mesma ordem.
- `js/`: scripts originais na ordem de execução, referenciados pelo HTML.
- `assets/`: imagens originais extraídas do HTML, sem redução de resolução.

## Publicação no GitHub Pages

Envie **todo o conteúdo desta pasta** para a raiz do repositório, preservando os nomes e caminhos. Em **Settings > Pages**, configure a publicação da branch principal e da pasta raiz (`/`).

Não publique somente o `index.html`: os estilos, scripts e imagens são arquivos externos.

## Observações

Os históricos e perfis permanecem no armazenamento local do navegador, não são compartilhados entre dispositivos. A leitura por OCR pode depender de conexão com a internet. As imagens extraídas foram preservadas em seus formatos originais.

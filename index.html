📄 Passo a passo: baixar o JSON do modelo no ERP

Use este guia antes de clicar em Importar JSON. O botão de cópia fornece o comando completo.

  1. Entre no ERP da CPlug e abra a tela de Modelos de etiquetas.
  2. Localize o modelo da impressora que deseja analisar e clique em Editar.
  3. Com a configuração do modelo aberta, pressione F12 (ou Ctrl + Shift + J) para abrir as ferramentas do navegador.
  4. Abra a aba Console e clique em Copiar script de extração abaixo, cole no Console e pressione Enter. Se o Chrome pedir confirmação para colar, confira o script antes de autorizar.
  5. O navegador deverá baixar campos_etiquetas_cplug.json. Verifique a pasta Downloads. Se não houver download, confira a mensagem do Console.
  6. Volte aqui, clique em Importar JSON e selecione o arquivo baixado.

Importante: o ERP não oferece necessariamente um botão nativo para exportar esse JSON. O botão “Exportar JSON” acima salva os dados deste aplicativo, não os dados diretamente do ERP. O script lê os campos disponíveis na tela e pode exigir adaptação dependendo do modelo do ERP; revise os dados importados antes de qualquer teste.

2. Impressão real

Anexe a impressão atual e, opcionalmente, uma captura do ERP. As imagens ficam somente nesta sessão; a captura do ERP pode ser lida por OCR com revisão dos campos.

A leitura usa OCR no navegador (Tesseract.js). Requer internet na primeira utilização. Confira os valores reconhecidos antes de aplicar; fotos da etiqueta não são interpretadas como configurações.

Limites importantes

A largura da folha, a largura de cada etiqueta, os espaços entre colunas e as margens devem ser medidos fisicamente. Se as três colunas estiverem deslocadas de maneira progressiva, verifique geometria da folha e calibração. Se o problema for apenas em um elemento, priorize os parâmetros dessa linha. Os controles de fonte são índices do ERP e não tamanhos em pontos.
